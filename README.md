# Supabase.Storage has moved

> [!IMPORTANT]
> This repository is **archived and read-only**. `Supabase.Storage` is now developed in the
> **[supabase-csharp](https://github.com/supabase-community/supabase-csharp)** monorepo,
> alongside the other Supabase .NET packages.

- **Source:** [supabase-csharp/packages/Storage](https://github.com/supabase-community/supabase-csharp/tree/master/packages/Storage)
- **Issues & pull requests:** [open them in the monorepo](https://github.com/supabase-community/supabase-csharp/issues)

## The NuGet package is unchanged

Only the repository has moved — [`Supabase.Storage`](https://www.nuget.org/packages/Supabase.Storage/) is still
published from the monorepo, so nothing changes for consumers:

```sh
dotnet add package Supabase.Storage
```
